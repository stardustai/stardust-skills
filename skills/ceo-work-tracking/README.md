# CEO Work Tracking

Extracts, creates, follows up, verifies, and closes durable work items from messages, meetings, and decisions.

Use this skill when losing the commitment would materially affect an established goal, delivery, decision, risk, or obligation. Use `ceo-message-triage` when no durable work item is needed.

Key boundaries:

- Load `dingtalk-todo`, `task-management`, and `dingtalk-chat` as needed before changing tracked work.
- Create a TODO only when there is a concrete deliverable and stable owner evidence.
- Bind every follow-up to an existing or newly created TODO.
- Read current project, TODO, and external status before sending a follow-up.
- Close or suppress follow-ups only when current evidence proves completion or cancellation.
