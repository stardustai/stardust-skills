# Candidate review card

For pre-screen exploration use [creative-round.md](creative-round.md). This card is for later formal review; empty screening fields do not mean creative drafts must be screened before user alignment.

- Name / route / round / generator / independent reviewer
- Primary creative row (`primary_creative_row`, separate from brand `route`) / creative plan and approval reference (`creative_plan_ref`) / source pool and entry membership
- First impression BEFORE origin story
- Attested source + URL / original meaning / creative association (separate)
- Primary construction operation / segment explanation / sound attributes
- Predicted pronunciation / stress / likely mishearing or misspelling
- Product-fit sentence / actual family combinations
- Rubric version / six scores, each reason and deduction
- Primary domain / exact quote and registry receipt references
- US query scope / controls / completeness / relevant records and goods/services
- Public-use queries / major observed users / catalog access limits
- Separate quality, domain and screening dispositions
- Human test NOT_DONE / lawyer clearance NOT_DONE / markets not covered
- Decision, principal risk, next required check
