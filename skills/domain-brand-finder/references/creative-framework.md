# 综合命名范式：先对齐创作，再过滤可用性

适用：确认词汇范围、扩展命名方法、按范式比较候选。只请求关键词、已有候选复核或域名查询时，不自动执行整套流程。项目定位、语言、词表、审美、数量和市场由当前需求决定，不能继承示例项目。

本框架把历史十二类和新增形变纳入同一个可扩展目录，不把十二类、七种操作或某批词缀当作唯一分类。历史项的逐条去向见 [case-study.md](case-study.md)。

## 1. 先确认原料范围

“常见”需要一个可复核的口径。为项目保存：词表名称、版本/获取时间、来源链接或本地文件、词形归一方式、允许的词类与词义、专名/外语/自由造词的处理、用户实际确认记录。建议与确认分开记录；用户要求扩展 Skill 不等于已经选定某份词表。

- **常见词池**：可选有版本的词频表、教学核心词表或用户词表。按词条核对，不把屈折形式和不同词性条目误当成不同原词来凑池子规模。不要凭印象声称已核对整份词表或精确词数。
- **专门来源池**：文学专名、地名、人名、科学人物、单位、外语词可单独建表，并给出真实性与熟悉度依据。它们不必永久排除，但不能自动获准进入封闭常见词池。
- **自由造词**：保留为可选方向；如果用户要求所有候选都有池内来源，则自由造词与该要求冲突，需要用户明确开放，不可伪造来源。
- **词缀与音形操作**：单独列出允许的规则，不要求 `co-`、`-ify` 等独立存在于原词表；不能借规则夹带池外的罕见词根。

例如英语项目可以提议 Oxford 5000。它由 Oxford 3000 和另外 2000 个扩展词构成，兼顾语料频率和学习相关性，并不是单纯词频前 5000，也不保证每个词都熟悉。以当时选择的版本/实际文件为准；有些名为 Oxford 5000 的下载文件只列扩展的 2000 词，不能把那一份当完整池。[Oxford 官方说明](https://www.oxfordlearnersdictionaries.com/about/wordlists/oxford3000-5000)

**约束输入，不把成品强行限制成词表中的原词。** 新名字允许形变；每个输入必须满足所选池和例外规则。截短一个池外词，并不会使其来源变成池内词。字母都来自常见词，也不等于生成的词让人熟悉。只使用已确认的常见词义，不能用池内普通词的冷僻义绕过熟悉度目标。

对有缺口的词条标记“未核对/池外/待开放来源”，不宣称已验证。不确认词表与专名边界时，可以讨论方案，但不以“已满足词汇范围”的名义大规模生成。

## 2. 四项记录，避免同义反复

| 记录项 | 回答的问题 | 不应混淆的东西 |
|---|---|---|
| 素材来源 | 从哪里找原词、物件或概念？ | 换一个学科不是换一种构造 |
| 实际构造操作 | 本轮究竟借用、复合、混成、截短、派生、改拼还是造词？ | 现成词的历史结构，不等于本轮真的做过形变 |
| 声音与字形 | 几音节、重音、节奏、辅音/元音、结尾、读写分歧？ | 单音节和两音节不自动算两种操作 |
| 直观品牌感受 | 不读解释时，是利落、有人格、轻巧、克制、开阔，还是其他气质？ | 多种操作也可能全部生成同一种气质 |

前三项是不同分析维度；第四项是独立的审美检查。气质由项目选，不把“伙伴”固定成可爱角色，也不把“智性”固定成科学术语或自然词加系统词。

**展示范式是一条具体创作任务，可以组合这些维度。** 例如“常见动作词 + co- + 简洁成熟的感觉”是一个可执行的展示行。`co-` 与 `re-` 可以各有五个候选；在上层操作统计中，它们仍同属派生。既不要虚报方法多样性，也不要因此禁止有用的细分模板。

## 3. 可选择、可扩展的范式目录

以下 23 行是第一版目录，不是默认全部执行的 115 个候选任务，也不是完整语言学分类。逐行选择/调整并确认本轮清单；未选择项仍保留在目录中。素材型模板默认整词借用；要在其上增加形变，先把组合写进本轮行定义，再按实际动作记操作。

### 素材与直接借用

| ID | 创作模板 | 原料与动作 | 重点比较 |
|---|---|---|---|
| S1 | 日常物件、材料词 | 从允许词池借用熟悉名词 | 具体但不琐碎，能否成为品牌而非物品说明 |
| S2 | 自然、空间、现象词 | 借用动物、植物、地貌、天气、光等真实词 | 画面、力量或空间感；不自动滑向田园诗 |
| S3 | 动作与状态词 | 借用常见动词或状态词 | 直接可感的态度；不强求描述产品功能 |
| S4 | 抽象认知、关系与秩序词 | 借用表达理解、判断、联系、变化等的真实词 | 智性但不以生僻为深度；原义与品牌联想分开 |
| S5 | 神话、文学及故事专名 | 从获准来源借用物件、人物、地点名称 | 无需长篇背景也有感觉；不虚构文化来源 |
| S6 | 地名与地域名称 | 从获准地理来源借用真实名称 | 地域联想与自然音感；区分地名和一般自然词 |
| S7 | 科学人物、单位与知识符号 | 从获准来源借用并核实指代 | 知识气质；不是只找最冷僻的科学词 |
| S8 | 人名、姓氏与人格称呼 | 从获准姓名来源借用 | 伙伴、机构或人格感，不默认只能像助手 |
| S9 | 外语真实词与约定转写 | 从获准语言词池借用，记录原文/原义/转写 | 声音与可理解联想；不把外来等同于高级或晦涩 |

神经科学、禅学、认知科学、信息论可为 S3/S4 等提供素材联想；学科名不是新增构造操作。若词池受限，用池内熟悉表达承载相关联想，不擅自搬入生僻术语。

### 构词与形变

| ID | 创作模板 | 操作与边界 | 重点比较 |
|---|---|---|---|
| T1 | `co- + 原词` | 符合共同、协同等意向的前缀派生；或明确记录为音形尝试 | 前缀是否自然，是否只是装饰 |
| T2 | `re- + 原词` | 符合再次、返回等意向的前缀派生 | 延续、更新与返工联想的差别 |
| T3 | `en-/em- + 原词` | 检查词性、含义与拼读是否允许自然派生 | 能力或状态变化；不机械套用 |
| T4 | `原词 + -er/-or` | 行动者或器具类派生，按实际来源解释 | 人格与能动性，是否过于通用工具化 |
| T5 | `原词 + -ify/-ize` | 使之成为或行动变化的派生尝试 | 活力与工具/命令感之间的取舍 |
| T6 | 性质、关系或方式后缀 | 如 `-ful/-less/-al/-ly`；选定具体后缀后检查词性和词义 | 名字整体是否成立；不能所有后缀随意互换 |
| T7 | 轻短称呼尾部 | 如 `-y/-ie`：实际派生、昵称化或改写需分别说明 | 自然称呼感，避免幼态和单一可爱气质 |
| T8 | 保留原词线索的尾部重塑 | 试 `-ar/-a/-o` 等尾部或元音变化；不默认是真实词缀派生 | 整体音形能否独立成立，熟悉线索是否消失 |
| T9 | 单词截短 | 对一个来源明确的词做截取，列出删除部分 | 短而完整，避免缩得只剩不可解的字母 |
| T10 | 轻度改拼 | 改变拼写，尽量保留来源词的读音与识别感 | 听写修复成本，不为将来域名预先怪拼 |
| T11 | 片段混成 | 两词截取片段后融合，写明保留/删除部分 | 整体自然度，不靠两个词根故事撑起名字 |
| T12 | 重叠混成 | 两词在字母或音节处重叠，明确重叠点 | 接合是否自然；与 T11 同属混成操作 |
| T13 | 完整短词复合 | 两个完整词直接组合；名词+名词、修饰词+名词等可细分 | 日常词的意外组合，避免全池同一种标题感 |
| T14 | 自由音形造词 | 没有可证词源的声音/字母创作；需词池规则允许 | 自己作为名字是否可信、好读；不得补写古老词源 |

`-ar` 不是任何词都能接的通用后缀。Cohere、Linear 本身是已有英语词；可以借鉴外形，但不能据此宣称品牌方发明了 `co + here` 或 `line + ear`。直接选择现成词，主操作为借用；本轮从池内原词实际尝试形变、后来发现已有同形词时，保留创作过程和已有词义两项记录，不混成一段词源故事。[Cohere 词典](https://www.merriam-webster.com/dictionary/cohere)、[Linear 词典](https://www.oxfordlearnersdictionaries.com/definition/english/linear)

T7/T8 等模板可能涉及不止一种操作。按实际动作选择主操作，辅操作另记；没有真实语义后缀就不能装成派生。纯字形改写可记改拼，片段重建可记截短加造词；解释判断，不为配额换标签。

### 声音形态：保留原第 9、10 类，不重复算量

- **单音节冲击型**：可以对 S1/S3 或获准造词加此目标，检查读音是否真为一个音节及传播代价。
- **两音节完整型**：可以与借用、派生、混成或造词组合，检查重音、节奏和听写，不把两音节自动视为优质。
- **较长但熟悉、流畅型**：作为可选比较，不以短为唯一标准。
- 可继续指定清脆/圆润、开口/闭口结尾、重叠节奏等声音目标，但这些是创作目标和桌面预测，不是受众测试结果。

若用户明确要求“单音节一组、两音节一组各五个”，可将它们定义成两条展示行，并写明各自允许的来源与操作。**每个名字只分配一个主展示行**，其他特征作为标签保留。不能把同一个两音节改拼名字同时充当三个组的名额。

## 4. 选择本轮行，再扩散

使用 [creative-round.md](../assets/creative-round.md) 保存可续跑计划。

1. 列出本轮使用的词池、例外范围和实际用户确认。范围冲突只询问关键选择，不让用户重填全部需求。
2. 从目录选择或新增具体展示行，写清输入、变化规则、声音/感受目标、排除项。针对历史十二项逐一记“保留/调整/待范围确认/本轮不选”及原因；不能因分类重整而让某方向无声消失。
3. 每个确认的行默认 **5 个独立创作候选**，用户指定数量优先。多个细分行可属于同一操作。若拆分一个后缀组，先确认新增行及总数量，不暗中把五个变成每个后缀五个。
4. 若用户要全面探索，应说明候选总量与适用范围；“全面”不等于所有来源×所有操作×所有声音的笛卡尔积。允许按确认的批次交付，但明确每行完成/缺口，不能只展示最容易写满的行。
5. 并发代理按行分工，输入一致；遵守指定模型。生成时同时保存两个工件：给主审的 `names-only`，以及当时就写定但暂不展示的密封来源卡（精确根词、保留字符跨度、插入/删除/重叠、实际操作）。主审先写完并冻结 names-only 判断，之后才打开来源卡。这样既不让故事给弱名字加分，也不因事后追溯而给同一表面词形编出多套词源。无法恢复唯一原始来源时标 `UNKNOWN`，不能挑一套最好听的解释。每行五个尽量使用不同原词与第一印象；同词根的轻微变体另放比较栏，不当五个独立创意凑数。

## 5. 创作对齐与核查分阶段

| 阶段 | 本阶段交付 | 下一阶段条件 |
|---|---|---|
| 词汇/范式计划 | 词池、范式表、每行数量、待确认选择 | 用户确认范围；已有确认可以复用 |
| 创作比较 | 每行 names-only 五项或约定数量；再附读音、来源、变形、第一联想和弱点 | 用户确认喜欢的名字/方向及可核查范围 |
| 核查与正式评审 | 对获准候选检查公开使用、域名与商标；正式质量分独立计算 | 达到约定证据与质量门槛 |
| 正式交付 | 合格项、证据和未完成边界 | 不把真人测试、律师或境外核查伪装成已做 |

创作稿不是正式 shortlist。创作阶段默认不给自动 90 分；如用户明确要评分，仍按固定标准独立评价，且不因要凑五个提高分。生成器已经写出的自评分及历史主审分保留在原始记录中；当前创作比较可以不展示这些分数，并明确“未作本轮独立评分/未采纳生成器分数”，不能用“撤销无效分数”之名删除或改写历史。没有查的项目标 **NOT_CHECKED**，不是“无冲突”。词典、概念和词源核实可做；商业公开使用、注册商、RDAP、商标、应用商店/开发者目录检索不能绕过用户要求的创作对齐门槛。已知碰撞如实备注，不冒称重新查询，也不让旧域名结果自动淘空某一范式。

用户明确委托端到端自主完成时，可按已授权范围衔接核查；仅“继续”、工具已经准备好、过去曾做核查、或批准改 Skill，不应被解读为取消当前的创作对齐要求。仅查域名或仅复核请求仍走相应入口，不强迫先做创作。

候选被核查过滤后，保留创作判断，回到用户认可的范式补充。若需要换词池或新方向，先标明变化并对齐。不要为了容易获得域名，把候选重新压缩成长复合词。

## 6. 交付前的两次多样性检查

**覆盖检查**：每行实际独立数、缺口；来源/构造是否真实；有无重复计数、池外词或未批准来源。没有达到五个时，继续同范围创作，或如实说明为何本轮不足，不能写成已完成。

**感受检查**：先不读故事，横向比较名字是否真的不同。不同学科或后缀是否仍全像温暖小工匠、科学术语、诗意复合标题？若是，调整原词和声音/态度目标；如超出原计划，呈现需要新增的比较方向。某个生硬名字不能因为来源解释漂亮而得到保留。

**反方校准边界**：独立批评者可以指出读写、自然度和路线适配被高估，但必须引用运行前冻结的行定义和评分标准。它临时提出的更严格偏好（例如“混成的两个根都不得完整保留”）只能作为新的比较假设，不能倒推成既有候选的规则违规。主审可因真实质量不足撤回分数，但要把“低于质量门槛”和“违反既定分类”分开记录。

**模板坍缩检查**：在 names-only 后统计相同尾音、前缀、第二词、重音轮廓和语义关系。以下情况即使换了根词也不算多样化：

- 把一组普通词统一改成 `-en/-el/-or/-ex` 等品牌尾音，却无法说明每个成品为何自然；“不在词典里”不是通过条件。
- 连续使用 `light/home/frame/forge/lock/wave/world` 一类共享尾词，只替换前半词。
- A 路线反复生成“信任形容词 + 助手角色”，B 路线反复生成“未来/星空词 + 技术物件”，前者像口号，后者像科幻标题。
- 将两个毫无可感关系的具体物体随机并置，再靠解释补出故事。

发现坍缩后，先记录失败批次，再改变**关系类型或实际操作**，不能只换更多同义根。若同一范式连续两到三轮仍坍缩，暂停该范式并交付缺口；这比为每类五个的表格目标保留弱名更有信息价值。进入来源卡的名字若被核实为另一操作（例如片段其实都是完整词），移动到真实行并释放原行名额，不能双计。

数量覆盖、审美判断、可用性核查是不同结论。五个创作稿可以完成一条探索行，但不能因此被标成五个 90 分、五个可用域名或五个商标初筛通过项。
