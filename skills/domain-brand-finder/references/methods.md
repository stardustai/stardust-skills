# Naming materials and construction

For the historical twelve-pattern mapping and reusable brand analyses, read [case-study.md](case-study.md) when explaining or comparing methodology. It distinguishes source evidence from interpretation.

For an executable vocabulary/pattern plan, read [creative-framework.md](creative-framework.md). It expands the historical directions into selectable creative templates; this file defines the underlying construction labels. Do not confuse the seven labels with the entire creative catalog.

## Three independent axes

1. **Material**: neuroscience, cognition, Zen, information theory, nature, objects, culture, actions/states, etc.
2. **Operation**: what was actually done to the words/sounds.
3. **Sound/form**: syllables, stress, likely pronunciation disagreements, spelling, length. These are properties, not extra methods.

Track the **perceptual route** alongside these axes: the immediate personality, image or attitude a name should convey. Neither three different source disciplines nor three operations guarantees three different brand feelings. A specific source+operation+form combination can be an agreed display row, but each candidate counts in only one row's quota.

For a real term, retain its source, original definition, and the proposed brand association in separate fields. Scientific or philosophical claims require primary/authoritative references. A dictionary meaning is not evidence that a founder intended it. An invented label may evoke a concept without being an authentic foreign word. Do not suggest fabricated Sanskrit/Greek/Latin origins.

## Operational labels

| Operation | Test | Important boundary |
|---|---|---|
| borrow | Use an attested whole word or proper name | Obscure vocabulary is not automatically deep or memorable |
| compound | Combine complete words | Dough + light is a compound, not a blend |
| blend | Clip/overlap two or more inputs into one | State the actual retained and lost segments |
| clip | Shorten one source word | Identify source and exact shortening |
| derive | Add a productive prefix/suffix to a base | Knead + -ful is derivation, not blending |
| respell | Alter the spelling of a source word | Record hearing-to-spelling and near-name risks |
| coin | Create a new sound/letter label without an attested lexical derivation | Do not invent an etymology afterwards |

These are practical non-exhaustive labels. If multiple operations truly occur, record primary and secondary; count the primary once. A foreign source is not a new operation. Neither two syllables nor “AI-inspired” is a construction method.

Label the action performed in this naming round, not merely the historical morphology of a dictionary word. Choosing the existing word `Guidance` is whole-word borrowing even though a linguist can analyze its suffix; choosing the existing object word `Handrail` is borrowing even though it contains two words. A newly constructed `Kneadful` demonstrates derivation only when the actual work was base `knead` + suffix `-ful`; a later exact-use check may still discover someone already uses that spelling. Do not relabel borrowed words to make an operation quota look filled. Preserve both the generator's proposed label and the principal's corrected label in the round audit.

## Round procedure

1. Save the brief, confirmed vocabulary pool/exception policy, selected creative rows with their per-row counts, prior exclusions with reasons, model and round IDs. Separate proposals from actual user approvals. Freeze a rubric only when numeric review is in scope.
2. Assign agreed creative rows to parallel agents. Every assignment retains the requested tone routes. Sources can overlap. No need to fill a Cartesian product of every discipline and operation or all catalog entries. Do not replace the selected rows with a smaller operation-only checklist.
3. Request names separately from origin cards so the principal reviewer sees names first. Generators flag weaknesses, not scores or legal availability.
4. Deduplicate spellings and near-identical templates. Retain provenance from multiple agents but count one name once. Report counts per selected row, not only a grand total. If a row lacks its requested five (or other configured count), complete it or record the exact gap; do not silently drop it or repeat one base with trivial variants.
5. Record first impressions before origin stories, then factual source checks and construction audit.
6. Show the per-row names-only comparison to the user, then source cards and independent qualitative observations. Compare operation distribution AND perceptual diversity among explored names and survivors. If over 60% of tentative finalists in one route use one operation, treat this as a diagnostic prompt for an alternative-method round, **not** a rigid quota or reason to promote weak names. If the user deliberately selected only prefix rows, report their shared derivation operation without expanding scope automatically.
7. Honor the creative-alignment gate before exact public product-use, domain and trademark searches. A patterns-only or keywords-only request stops at that artifact. After approval/explicit end-to-end authorization, run the agreed checks before formal evaluation, then independent scores and evidence review. Persist rejections; replenish within the approved creative directions rather than changing the aesthetic to chase available domains.

Names such as “calm + object”, “adjective + bird”, and “scientific root + action” can all be full-word compounds. Replacing the words is not method coverage.

## Borrow the craft, not claims of guaranteed success

The supplied 500-company naming map is a historically bounded, heavily YC-oriented sample. It is useful for observing construction, not for estimating success rates, causal naming effects or universal category shares. Its nine prototypes and historical twelve-method notes mix different axes; neither is complete or mutually exclusive.

Useful hypotheses to test, not rules:

- A familiar anchor plus a surprising twist can create recall, but two roots are not mandatory.
- A brand can sit above one technical feature, but literal naming may suit another product's brief.
- Concrete objects or phenomena can create imagery; abstract names can work if the sound and usage carry them.
- Shorter is not automatically better: ambiguity, spelling repair and generic search noise matter.
- Test the actual product family, not just the isolated logo name.
- Domain scarcity must not silently force every survivor into two-word compounds.

For a documented example, Gumloop's own [renaming account](https://www.gumloop.com/blog/agenthub-to-gumloop) is primary evidence about that company's decision. Analyze other brands' construction as your interpretation unless a primary source establishes founder intent. Refresh sources before repeating current business or ownership claims.

## Source-card template

- Term / source discipline / authoritative URL / access date
- Attested definition (short paraphrase)
- Brand association (explicitly creative, not the original definition)
- Proposed operation and segment derivation
- Sound prediction and common mishearing
- Why the name has an immediate image or feeling without the story
- Route fit, caveat, and what would falsify the recommendation
