# CEO Document Review

Reviews DingTalk or Lark documents, files, images, tables, and linked materials from the current source request.

Use this skill when the main task is to inspect, summarize, compare, comment on, or approve a material. Use mail, meeting, or personnel skills when the enclosing workflow changes the decision boundary.

Key boundaries:

- Identify the real material type before reading it.
- Load the matching operation skill, such as `dingtalk-doc`, `dingtalk-aitable`, `dingtalk-drive`, `lark-doc`, `lark-base`, or `lark-drive`.
- Inspect attached images directly when they are present in the current input.
- Reread material when it changed or received new comments.
- Do not infer content from titles, captions, previews, or stale conclusions.
